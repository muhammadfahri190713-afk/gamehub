# GameHub

GameHub offline-first untuk browser desktop dan HP, berisi 140 mini-game dengan animasi, suara opsional, tema, filter, skor lokal, dan kontrol sentuh.

## Menjalankan

Buka `index.html` langsung di Chrome, Edge, Firefox, atau Safari modern. Tidak membutuhkan server atau internet untuk bermain.

## Isi

- 29 game inti
- 87 game tambahan
- 24 game challenge tambahan
- Web Audio opsional, tema, fullscreen, pencarian, filter, localStorage, dan reduced-motion support
